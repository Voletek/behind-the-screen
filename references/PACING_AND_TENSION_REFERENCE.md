# Pacing and Tension Reference

> Tools for `core/methodology/running-the-game.md` → Session Structure. The GM equivalent of
> arrangement and dynamics: when to push, when to breathe.

---

## The Tension Curve of a Session

```
tension
  ▲                                   ╭─╮ CLIMAX
  │                     ╭──╮        ╭─╯ ╰╮
  │   STRONG        ╭───╯  ╰─╮   ╭──╯     │
  │   START ╭─╮  ╭──╯        ╰───╯        ╰─╮ RELEASE
  │  ╭──────╯ ╰──╯                           ╰──── save state
  └────────────────────────────────────────────────────────▶ time
     recap  scene 1   scene 2   scene 3   scene 4   closing
```

- Alternate: **tension → release → higher tension**. Never two quiet scenes in a row unless the table
  asked for a slow session.
- Every scene should be at a different intensity from the last.

## Pacing Levers

| Lever | Speeds up | Slows down |
|---|---|---|
| Scene length | Cut when the question is answered | Linger on a quiet character beat |
| Description | One sentence, one detail | Full sensory frame |
| Time skips | "Three days later…" | Play it out minute by minute |
| Rolls | Group rolls, no roll | Individual rolls, extended conflict |
| Choices | Two clear options | An open situation |
| NPC lines | One line each | Conversation |
| Combat | Mooks drop on any hit; morale breaks | Full tactical rounds |

## Tension Tools

| Tool | How |
|---|---|
| **Clocks** | A visible countdown (4/6/8 segments). Tick on failures, delays, noise |
| **Ticking cost** | Light running out, oxygen, rations, a fever |
| **Telegraphed threat** | Show the monster's tracks, hear it before seeing it |
| **Hard choice** | Two things the PCs want; they can only have one |
| **Split attention** | Two problems at once (the fire and the fight) |
| **Information asymmetry** | Players know something characters don't (or vice versa) |
| **Silence** | In horror: a short message after a long one. "Nothing answers." |
| **Escalation ladder** | Each failure or delay raises the stakes one step |

## Release Tools

Campfire scenes, loot and healing, a joke from a companion, a beautiful vista, a letter from home,
shopping montage, levelling up, a safe haven.

## Spotlight Rotation (group)

```
After resolving player A → turn to the player with the lowest spotlight count
If two are tied → the one whose PC goal fits the current scene
Every 3-4 exchanges → check counts
```

## Message Length Guide (text chat) [Tier 3]

| Moment | GM message length |
|---|---|
| New location | 3-6 sentences |
| Continuing scene | 1-3 sentences |
| Combat round (GM side) | 1-2 sentences per enemy + tracker |
| NPC dialogue | ≤ 3 sentences per NPC turn |
| Climax reveal | Can run longer; earn it |
| Recap | 3-5 bullets |

## Ending a Session Well

- End on a **cliffhanger** (campaign) or **resolution** (one-shot).
- Leave 10% of the session for closing and the save. A session without a save is lost state.
