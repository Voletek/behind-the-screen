# Character Creation Skill

Read `core/methodology/character-creation.md` before applying this skill (if not already in context).

Read `systems/<id>/PROFILE.md` → Characters and Advancement for the system in play. List methods with `python3 tools/character.py methods --system <id>`.

Create and check with `python3 tools/character.py new …` and `python3 tools/character.py check --campaign <dir>`.
