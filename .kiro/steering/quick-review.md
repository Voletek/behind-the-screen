# Quick Review (manual command)

> Run with `/quick-review` or `#quick-review`. Rubric: `core/methodology/session-review.md`
> (canonical). Read it if it isn't in context.

1. If a shell is available: `python3 tools/validate-campaign.py campaigns/<id>`.
2. Score the 12 craft categories (1-10), one sentence each: Player Agency, Pacing, Scene Framing,
   Adjudication, Rules Fidelity, Dice Honesty, NPC Voice, World Consistency, Spotlight Balance,
   Tone Fidelity, Safety & Consent, Fun & Momentum.
3. Core composite and decision gate: ≥8.5 strong · 7.0-8.4 tune it · <7.0 rethink. Any line crossed →
   stop and repair.
4. Quote the best GM moment.
5. Flag the single biggest issue with a concrete alternative.

Keep it short. For the full report, use the session-critic agent or `.kiro/sops/07-reviewing-a-session.md`.
