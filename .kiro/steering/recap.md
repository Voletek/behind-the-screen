# Recap (manual command)

> Run with `/recap` or `#recap`. Canonical: `core/methodology/running-the-game.md` → Opening, and
> `core/methodology/state-keeping.md` → Start-of-Session Load.

1. Read `BIBLE.md`, `state.json`, the latest session log, and the latest prep.
2. Confirm three facts with the player: where they are, the most important resource/condition, and
   the main open question. Fix the files if the player corrects you.
3. Recap in 3-5 bullets (in a group, ask a player to recap first and correct only factual errors).
4. Open with the strong start from the prep, or improvise one from `## Next Session`.
