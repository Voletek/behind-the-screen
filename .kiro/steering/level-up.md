# Level Up / Change a Character (manual command)

> Run with `/level-up` or `#level-up`. Canonical: `core/methodology/character-creation.md` →
> Customization During a Campaign, Advancement.

1. Ask which character and what's changing.
2. Advancement: say what the system grants (profile → Advancement), list the options, let the player
   choose; they roll any advancement dice (or take the fixed value).
3. Other changes: route by the customization table (look and name any time; backstory before it
   appears in play; rebuild per the table setting).
4. Update the sheet's `## Changes` and the numbers in `state.json`; run `tools/character.py check`.
