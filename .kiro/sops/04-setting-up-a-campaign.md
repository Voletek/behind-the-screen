# SOP 04: Setting Up a Campaign

> Build the campaign bible, fronts, arc map and continuity rules.
>
> **Canonical method:** `core/methodology/campaign-continuity.md` Part 1. This SOP is the step list; if they diverge, `core/` wins.
> **Agent:** builder + continuity-keeper · **Time:** 1-3 hrs

---

## Prerequisites

- Session zero done (SOP 01)
- Any source canon (novel, album, module) gathered

## Procedure

1. Premise and thesis line.
2. Tone, safety, table settings, house rules (from session zero).
3. Characters: goals, bonds, flaws.
4. Setting canon: only what Arc I needs.
5. 2-4 fronts, each with a clock and an "if unopposed" outcome.
6. Arc map of dramatic questions.
7. Recurring motifs.
8. Checkable continuity rules.
9. If adapting source canon: list conflicts between sources as Open Canon Questions; add Retired Terms.
10. state.json with factions, clocks, threads.
11. Validate; optionally add campaign steering and a continuity hook (copy from `examples/campaigns/fractured-shadows/`).
12. Save/commit before session 1.

## Done When

- [ ] Bible validates · [ ] every front has a clock · [ ] arcs are questions · [ ] source conflicts listed, not resolved
