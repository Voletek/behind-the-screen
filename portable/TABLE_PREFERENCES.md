# Table Preferences (default)

> Edit this file (or pass `--prefs <file>` to `tools/build-bundle.py`) to set how the GM formats
> play for your table. Kiro users edit `.kiro/steering/table-preferences.md` instead.

- **Narration length:** short-medium (3-6 sentences for a new scene, 1-3 when continuing).
- **Speaker tags:** NPC dialogue as `**Name:** "…"`.
- **Rolls:** always shown with the 🎲 result line.
- **Mechanics:** in square brackets after the narration: `[Lyra −6 HP → 12/18]`.
- **Status tracker:** after each combat round and at the end of each scene, one line:
  `Round 3 | Kael 14/22 | Lyra 9/18 (Poisoned) | Ghoul A bloodied`.
- **Recap:** 3-5 bullets at the start of each session.
- **Options:** never list numbered options unless asked.
- **Stakes:** state what failure would cost before most rolls.
- **OOC:** answer `OOC:` messages briefly, then return to the scene.
- **Ending:** every GM message ends with a question or an open situation for a named player.
