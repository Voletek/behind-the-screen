# experiments/ai-gm/ — AI GM Behaviour Logs

Evidence for the Tier 3 claims in `references/AI_GM_FAILURE_MODES.md`. One YAML file per experiment:
`YYYY-MM-DD-<slug>.yml`, copied from `TEMPLATE.yml`.

Promotion rule: an observation reproduced in 3+ sessions (ideally two campaigns) is promoted into the
failure-modes reference with a link to its log. Re-test entries older than ~6 months; models change.
